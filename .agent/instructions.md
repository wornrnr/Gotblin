# Agent Interaction Rules & Guidelines

## 1. 질문 및 분석 요청 관련 작업 지침 (User Interaction Rule)
- **사전 프로젝트 수정 금지**: 유저가 질문을 하거나 코드/프로젝트 분석을 요청할 때는 **절대로 사전에 코드를 직접 수정하지 마십시오**.
- **답변 및 분석 선행**: 요청받은 내용에 대해 분석 결과 및 답변을 먼저 상세히 설명하십시오.
- **수정 여부 확인**: 답변 후 유저에게 코드 수정 진행 여부를 확인하고, 유저의 명확한 승인을 받은 후에만 프로젝트 파일 수정을 진행하십시오.

## 2. 응답 언어 (Language Rule)
- 모든 대답은 **한국어**로 작성하십시오.
